Fundamentos

Las Listas Enlazadas son las estructuras de datos fundamentales, ya que a partir de su implementación se pueden crear una gran variedad de estructuras de datos

Los cuatro pilares de una estructura enlazada

🔹

NODO (Node)

La unidad mínima. Un nodo guarda dos cosas: un dato (el valor) y un next (la referencia al nodo siguiente). Es el "eslabón" de la cadena.

🎯

HEAD

El puntero de entrada. Si conoces head, puedes recorrer toda la lista. Si head es null, la lista está vacía.

➡️

PUNTERO NEXT

Cada nodo apunta al siguiente mediante next. Los nodos no están contiguos en memoria: pueden estar dispersos. El puntero es el hilo que los conecta.

⛔

NULL / TAIL

El último nodo apunta a null (o None, nullptr). Esa marca indica el final del camino y detiene los recorridos.

ANALOGÍA: Piensa en un rally de pistas. No sabes de antemano cuántas pistas habrá. Cada sobre contiene una dirección y dentro está la dirección del siguiente sobre. Solo necesitas la dirección del primero (HEAD) para seguir toda la cadena. Un array es una fila de casas numeradas; una lista enlazada es un tesoro con pistas encadenadas.
⚖️

ARRAY vs LISTA ENLAZADA

Array: acceso por índice O(1), tamaño fijo, inserción costosa.
Lista: acceso secuencial O(n), tamaño dinámico, inserción/borrado baratos si ya tienes el nodo.

🧠

MEMORIA

Cada nodo se asigna dinámicamente (new, malloc). Por eso en C/C++ es vital liberar con delete/free. En Java, Python o JS, el recolector de basura lo hace por ti.

⚠️

RIESGOS

Perder head = perder toda la lista. Olvidar reconectar next = perder la cola. Un next mal apuntado = bucle infinito.

Tipos

Variantes de la estructura enlazada

SIMPLE

Lista Simplemente Enlazada

Un solo sentido: de head hacia null. No se puede retroceder.

  • Menos memoria por nodo
  • Recorrido solo hacia adelante
  • Base de pilas y colas
DOBLE

Lista Doblemente Enlazada

Cada nodo tiene next y prev: se viaja en ambos sentidos.

  • Borrado O(1) si tienes el nodo
  • Recorrido bidireccional
  • Usada en historiales y navegadores
CIRCULAR

Lista Circular

El último nodo apunta de nuevo a head. No existe null.

  • Ideal para turnos / round-robin
  • Cuidado: riesgo de bucle infinito
  • Usada en buffers y reproductores
